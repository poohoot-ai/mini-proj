## 시크릿 처리 원칙

- 실제 API 키는 프로젝트 루트의 `.env`에만 사용하고 Git에 커밋하지 않는다.
- `.env.example`에는 변수명과 비밀이 아닌 기본값만 기록한다.
- Streamlit 화면, 브라우저 응답, 구조화 로그, Docker 이미지에 API 키를 노출하지 않는다.
- 키 확인 시 존재 여부만 검사하며 값을 출력하지 않는다.
- 외부 API 검증은 사용자의 명시적 승인 후 최소 요청으로 수행한다.
